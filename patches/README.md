# Patch

`skyward-oneplus-piano-waffle.patch` is the diff from upstream
`kirklin/skyward` 0.3.1 to the tree in `../skyward`. It applies with
`git apply -p1` at the root of a fresh upstream checkout.

It contains the OnePlus compatibility work from
`shawude/skyward-oneplus13-sun` plus `devices/piano.toml` and
`devices/waffle.toml`. No other source changes were made for this port.
